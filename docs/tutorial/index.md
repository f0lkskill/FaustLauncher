## 这个教程的写法

**先用包装好的函数，再讲它背后的东西。** 前七篇你不会看到类名、方法名、内存偏移这些
东西——你需要的是 `game.popup()`、`game.units()`、`u.hp` 这样一句话就能用的接口。
第 08 篇才下潜到钩子和读链，那是给「想改游戏行为」的人准备的。

## 读之前需要知道的四个词

- **钩子（hook）**：在游戏的某个函数上挂一个回调，函数一被调用就通知你（或干脆不让它执行）。
- **读链（read chain）**：一串「先加偏移、再解引用、再进容器」的步骤，用来从一个对象走到你关心的字段。
- **对象槽（object slot）**：共享内存里的 32 个格子，用来临时存放「某个游戏对象的指针」，之后可以反复对它读数。
- **命名空间（namespace）**：插件之间的分工方式。`WarpHook` 提供 `warp`，你的插件也能注册自己的让别人用。

前七篇几乎不用直接碰后三个词——它们藏在 `warp.game` 里面。
