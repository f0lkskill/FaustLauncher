## 📖 关于 FaustLauncher

> 浮士德启动器（FaustLauncher）是一款为《边狱巴士》玩家打造的全功能启动器，集 Mod 管理、界面美化、超链接迁移、自定义汉化等实用工具于一体。  
> **关于使用视频教程，可以在程序「关于」页面了解更多。**

---

## 🧩 插件系统（v0.6.0+）

自 `0.6.0` 版本起，FaustLauncher 支持**用户自编写插件**，扩展启动器功能。

📘 **[→ 插件制作指南](https://github.com/f0lkskill/FaustLauncher/blob/main/MakeAnAddon.md)**

---

## ✨ 核心功能

| 功能模块 | 说明 |
|---------|------|
| 🎮 **Mod 管理** | 添加 / 删除 / 启用 / 禁用 Mod，管理你的模组库 |
| 🎨 **气泡渐变色** | 为游戏内气泡文本添加渐变色彩，视觉更舒适 |
| ⚙️ **设置中心** | 自定义用户名（显示在个人车票上）等多种个性化选项 |
| 🔗 **超链接创建器** | 解决 C 盘资源占用问题 — 移动资源文件夹并创建符号链接 |
| 📝 **自定义汉化** | 用户可自行修改制作个性汉化包，修改内容自动记录，不与渐变色冲突（**记得手动保存**） |
| 🌈 **渐变色生成器** | 生成 Unity 渐变色富文本，可用于修改技能名称等 |
