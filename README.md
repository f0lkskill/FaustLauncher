## 📖 关于 FaustLauncher

> 浮士德启动器（FaustLauncher）是一款为《边狱巴士》玩家打造的全功能启动器，集 Mod 管理、界面美化、超链接迁移、自定义汉化等实用工具于一体。  
> **📺 使用视频教程：可在程序「关于」页面查看。**

## 🧩 插件系统（v0.6.0+）

自 `0.6.0` 版本起，FaustLauncher 支持**用户自编写插件**，扩展启动器功能。

📘 **[→ 插件制作指南](https://github.com/f0lkskill/FaustLauncher/blob/main/MakeAnAddon.md)**

<br>

## ✨ 核心功能

| 功能模块 | 说明 | 状态 |
|:---|:---|:---:|
| 🎮 **Mod 管理** | 添加 / 删除 / 启用 / 禁用 Mod | 🚧 暂不可用 |
| 🎨 **气泡渐变色** | 为气泡文本添加渐变色彩 | ✅ 可用 |
| ⚙️ **设置中心** | 自定义用户名、车票显示等 | ✅ 可用 |
| 🔗 **超链接创建器** | 移动资源文件夹并创建符号链接，释放 C 盘空间 | ✅ 可用 |
| 📝 **自定义汉化** | 自制个性汉化包，记录修改，不与渐变色冲突 | ✅ 可用 |
| 🌈 **渐变色生成器** | 生成 Unity 渐变色富文本，可改技能名称 | ✅ 可用 |

### 📌 功能详情

<details>
<summary><b>🎮 Mod 管理</b>（点击展开）</summary>

- 支持添加/删除 Mod
- 支持启用/禁用 Mod
- ⚠️ 当前因游戏引擎更新暂不可用，预计后续版本修复
</details>

<details>
<summary><b>🎨 气泡渐变色</b></summary>

- 为游戏内气泡文本增加渐变色效果
- 可在设置中调整渐变系数
- 与自定义汉化互不冲突
</details>

<details>
<summary><b>🔗 超链接创建器</b></summary>

1. 将资源文件夹移动到其他盘符
2. 选择移动后的文件夹路径
3. 选择原资源文件夹目录
4. 授予管理员权限，自动创建符号链接
</details>
