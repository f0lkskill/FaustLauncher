## ✨ 功能详解

### 🚀 一键启动（流水线式）

点击「🚀 启动游戏」，自动按顺序完成以下全部步骤 — **无需任何手动操作**：

| 步骤 | 内容 |
|:---|:---|
| 1️⃣ 汉化下载更新 | 自动检测并下载零协会最新汉化包 + 气泡文本 Mod（多下载源） |
| 2️⃣ 复制汉化文件 | 将 `lang/LLC_zh-CN` 同步到游戏目录 |
| 3️⃣ 应用拓展汉化修改 | 一键应用全部已启用的 Mod / 插件 / 自定义翻译补丁（`changes.json`） |
| 4️⃣ 应用美化功能 | 气泡渐变 · 技能描述 · EGO 样式 · 私活 Tip · 技能渐变色 |
| 5️⃣ 复制字体文件 | 内置字体自动部署到游戏汉化目录 |
| 6️⃣ 创建零协会配置 | 自动生成汉化所需配置文件 |
| 7️⃣ 设置用户名称 | 将您的用户名写入车票（`UserInfo_Friends.json`） |
| 8️⃣ 插件事件 + 载入游戏 | 触发插件启动事件，加载 Mod 并正式启动游戏 |

> 非关键步骤失败不会阻塞启动；关键步骤（汉化复制 / 字体）失败会弹窗提示。

### 🌐 汉化系统

- **零协会汉化自动更新**：内置 4 种下载源，一键切换
  - ☁️ 蓝奏云转存下载源（推荐）
  - ⚡ gh-proxy 代理加速下载
  - 🔄 upfile 动态更新下载源
  - 🐙 GitHub Releases 官方下载源（网络环境要求高，不推荐）
- **气泡文本 Mod 自动更新下载**（提取码：fib6）
- 支持手动更新汉化（首页「🎯 汉化更新」按钮）

### 🎨 游戏美化功能

| 功能 | 说明 |
|:---|:---|
| 🫧 气泡文本渐变色 | 对话气泡文本渐变配色，可调节**渐变系数** |
| 💠 技能名称渐变色 | 依据技能罪孽颜色自动添加渐变色 |
| 📝 技能描述美化 | 数字特殊样式、`>` `<` 规范化等 |
| ✨ EGO 样式美化 | 正常 / 侵蚀 EGO 名称特殊样式 |
| 🗣️ 零协会私活 Tip | 替换战斗文本提示 |
| 🧾 用户车票名 | 名片上显示自定义用户名 |
| 🔤 自定义字体 | 用您喜欢的字体替换汉化包字体 |

### 🧩 Mod 与插件系统

- 📥 **Mod 管理**：添加 / 删除 / 启用 / 禁用，支持外置 Mod 加载器
- 🔌 **插件系统（v0.6.0+）**：用户可自编写插件扩展启动器
  - 📘 **[插件制作指南](MakeAnAddon.md)**
  - 支持启动事件钩子、`changes.json` 汉化补丁、图标与资源打包
- ⚠️ 当前受游戏引擎更新影响，Mod 兼容性修复中（见上）

### 📝 自定义翻译器（changes.json 补丁）

- 可视化修改游戏内任意文本，自动生成并保存为 `lang/changes.json`
- 补丁天然跨设备可移植，可随 Mod / 插件打包分发
- **与美化渐变功能互不冲突**

### 🤖 AI 自动翻译

- 使用**思知 AI** 对游戏文本进行**批量自动翻译**（工具页 → 自动汉化）
- 在「设置 → 翻译」页配置 AI 密钥与提示词，提示词支持 `{text}` 占位替换
