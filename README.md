## ✨ 功能详解

### 🚀 一键启动（流水线式）

点击「🚀 启动游戏」，自动按顺序完成以下全部步骤 — **无需任何手动操作**：

| 步骤 | 内容 |
|:---|:---|
| 1️⃣ 汉化下载更新 | 自动检测并下载零协会最新汉化包 + 气泡文本 Mod（多下载源） |
| 2️⃣ 复制汉化文件 | 将 `lang/LLC_zh-CN` 同步到游戏目录 |
| 3️⃣ 应用拓展汉化修改 | 只应用**已启用**的 Mod / 插件 / 自定义翻译补丁（`changes.json`）；被禁用的资源**不应用**，并自动把它上次改过的文本**还原**回原始内容 |
| 4️⃣ 应用美化功能 | 气泡渐变 · 技能描述 · EGO 样式 · 私活 Tip · 技能渐变色 |
| 5️⃣ 复制字体文件 | 内置字体自动部署到游戏汉化目录 |
| 6️⃣ 创建零协会配置 | 自动生成汉化所需配置文件 |
| 7️⃣ 设置用户名称 | 将您的用户名写入车票（`UserInfo_Friends.json`） |
| 8️⃣ 插件事件 + 载入游戏 | 触发插件启动事件，加载 Mod 并正式启动游戏 |

> 非关键步骤失败不会阻塞启动；关键步骤（汉化复制 / 字体）失败会弹窗提示。

### 🌐 汉化系统

- **零协会汉化自动更新**：内置 4 种下载源，一键切换
  - ☁️ 蓝奏云转存下载源（推荐）
  - ⚡ gh-proxy 代理加速下载
  - 🔄 upfile 动态更新下载源
  - 🐙 GitHub Releases 官方下载源（网络环境要求高，不推荐）
- **气泡文本 Mod 自动更新下载**（提取码：fib6）
- **蓝奏云直链本地解析**：所有蓝奏云下载（汉化包 / 字体包 / Mod / 插件 / 图标）在下载前由启动器本地解析成直链，含阿里云 WAF 挑战求解与 302 跳转跟踪，不依赖第三方解析服务
- **解析结果持久缓存**：解析结果按「源 URL → 直链」落盘（`cache/lanzou_links.json`）。蓝奏云直链本身约 30 分钟失效，所以缓存按 25 分钟有效、**用前自动重新解析**；万一链接提前失效，下载会自动丢掉缓存重解析一次。源 URL 一换（重新上传 / 条目改链接）就是新键，自然重新解析
- **文本补丁（`changes.json`）的启用规则**：应用前先看资源是否被禁用（与资源管理页同一判定：插件默认启用、Mod 默认禁用）；禁用的**不应用**，而且会按快照还原它上次改过的文本 —— 因为补丁会写进游戏 Lang 下**所有**含该文件的汉化文件夹（`LLC_zh-CN` / `LCTA` / `LCTA_AU`…），而启动器每次只用汉化包重建**当前平台**那一个，不还原的话那些文件夹里的旧文本会一直生效。快照在 `cache/changes_backup/<addons|mods>/<资源目录>/`（`index.json` + 原始文件），资源卸载后自动清理；目标文件比快照新（被别的插件/汉化包重写过）时保持现状不还原
- **请求节流 + 限流保护**：蓝奏云 downprocess 接口有 IP 频控。节流按域名各自一个**令牌桶**：一页图标（默认 4 个）可以**并发起步**不被串行化，额度用完才按 `lanzou.min_interval_sec`（默认 1.5 秒）匀速补充，页面 GET 基本放开；命中限流后进入冷却（120 秒起、最长 15 分钟、跨重启保留），冷却期间直接用已缓存的直链、不再撞墙
- **图标缓存自动维护**：图标下载会校验内容并本地缓存，**按 `icon_url` 哈希命中（条目改名也能复用旧缓存）**，抽屉 / 下载中心 / 网页端共用同一份缓存，命中就完全不发请求；云端已下架的图标缓存自动清理
- **图标加载动画**：随机推荐 / 下载中心 / 下载任务抽屉的图标，在解析下载期间显示圆环加载动画（颜色跟随主题），拿到后淡入显示，不再"先亮占位图再跳变"；同一个 url 并发只请求一次
- **图标加载时序保护**：图标水合等 app 就绪（bootstrap 拿到）后再延后一点才开始，且**同时最多 4 个请求**、彼此错开——避免启动瞬间几十个图标一起砸后端被蓝奏云限流 / 超时，导致"首次进入图标全成兜底图"；单次失败会立刻回退兜底图（不卡住加载动画），随后按 5s / 20s / 65s 后台重试，重试成功自动把页面上同 url 的图标补上（后端失败负缓存只有 60 秒）
- **主页称呼与汉化源**：主页"您好，xxx"读设置里的玩家名（默认 Player），改设置立即同步；"汉化源"芯片以后端为准 —— 插件注册了自定义汉化源时显示**第一个**的名字（插件加载/重载后自动同步）
- **资源路径规则（重要）**：pywebview 加载本地页面时是**起一个本地 HTTP 服务**（服务根 = `html/app/`），页面里 `../../assets/...` 这类越界相对路径一律 404、显示成坏图。所以前端要用的图片要么放 `html/app/` 内（项目图标已复制一份到 `html/app/assets/icon/icon.png` 作为首屏兜底），要么走后端内嵌的 data URI（快捷方式 / 工具卡 / 角色小人 / 云端图标都是这么来的）。`refreshProjectIcons()` 会在拿到 bootstrap 图标后再把所有标记了 `data-project-icon` 的图标重挂一遍
- **游戏路径确认窗等窗口就绪后才弹**：启动时先锁住界面（不可点），等 splash 收尾、bootstrap 就绪（项目图标已是 data URI）之后才真正弹窗——入场动画播在用户看得见的时候，也不会再出现模态上项目图标坏图
- 支持手动更新汉化（首页「🎯 汉化更新」按钮）

### ☁️ 云端数据（webnote）与网络排障

启动器的在线资源列表、更新说明、汉化版本号等来自云端笔记。**读取与写回是两条独立链路**：

| 配置项 | 默认值 | 用途 |
|:---|:---|:---|
| `webnote_bases` | `https://folkskill.pythonanywhere.com/note/{key}` | **读取**源模板列表（`{key}` 占位符），按顺序尝试、自动回退 |
| `webnote_update_url` | `https://folkskill.pythonanywhere.com/update/` | **写回**地址（下载计数 / 排序上传） |

> 写回固定用 **POST**（`key` 在 query、`value` 在表单体）。`/update/` 用 GET 时 `value` 会进 URL，
> 20KB+ 的真实笔记会被 openresty 以 **414 Request-URI Too Large** 拒绝，因此代码里 GET 只用于极小内容兜底。

#### 国内线路加固（为什么以前"南方用户全挂、浏览器却正常"）

浏览器自带 DoH、Happy Eyeballs（IPv6 自动回落）和 QUIC，而 Python 的 `requests` 一样都没有；
再加上旧实现是「单域名 + 无超时 + 异常被吞掉」，线路一抖就整段失败且不留原因。现在读取链路上有：

1. **多源兜底**：`webnote_bases` 依次尝试
2. **超时 + 重试**：连接类错误换协议栈/退避重试，不会再无超时挂死
3. **IPv4 优先**：首次强制 `AF_INET`，避开线路 IPv6 半通
4. **DoH 兜底**：常规线路失败时用 `223.5.5.5` / `doh.pub` 解析，再按原域名 SNI 直连 IP（绕过 DNS 污染）
5. **本地缓存兜底**：全部失败时使用 `cache/webnote/<key>.txt`，启动器仍可用（可能过期）
6. **明确日志**：每次尝试都打印 `[云端] ...` 到「终端」面板与 `logs/`，失败不再静默

#### 仍有个别用户失败怎么办

优先加**第二个镜像源**（不需要自有域名，`webnote_bases` 直接追加即可）：

```json
"webnote_bases": [
  "https://folkskill.pythonanywhere.com/note/{key}",
  "https://gitee.com/<用户名>/<仓库>/raw/main/notes/{key}.json",
  "https://<bucket>.cos.ap-shanghai.myqcloud.com/notes/{key}.json",
  "https://cdn.jsdelivr.net/gh/<用户名>/<仓库>@main/notes/{key}.json"
]
```

同一份笔记 JSON 放多处即可，启动器会按顺序自动回退。

排障工具：`python webnote_diag.py` 会逐项打印 DNS（系统 vs DoH）、TCP / TLS / HTTP 耗时与结果、本地缓存状态。

**缓存策略（重要）**：

- 每次启动都会重新联网获取，**不会拿上次的旧内容**（发布新版本 / 新 Mod 后重启即可看到）；
- 同一次启动内的重复请求会合并（进程内记忆 30 秒），不重复打云端；
- `cache/webnote/` 只在**网络失败时兜底**（离线时仍能启动，内容可能过期，日志会明确提示）；
- 手动刷新一定联网：主页「检查更新」、版本窗口、下载中心的 **⟳ 刷新** 按钮都会忽略本次启动已获取的内容；
- 想彻底清掉本地兜底：删除 `cache/webnote/` 目录即可（下次成功联网时自动重建）。
日志里 `[云端]` 行也能直接定位层级：`ConnectTimeout/ReadTimeout` 是线路问题，
`SSLError/ConnectionReset` 是中间设备干扰，`HTTP 200 但内容为空` 是笔记名/迁移问题，
`HTTP 403/502` 多为云端配额或服务异常。

| 其它 | 欢迎音效（wav 自定义）、背景模糊强度、主题颜色（实验性） |

**游戏路径（硬性要求）**：启动器启动时会解析 Steam 的 VDF 文件自动定位边狱巴士，
但**路径必须真的包含 `LimbusCompany.exe`** —— 没这个文件的目录（包括 Steam 自动检测到的）
一律视为无效路径：

- **Web（窗口）模式**：弹出确认窗口问"这是你的游戏路径吗？"。检测到的路径里没有
  `LimbusCompany.exe`、或压根没检测到，就直接要求手动选择目录；**没选出有效路径之前界面
  被完全锁住**（没有关闭按钮，点遮罩 / Esc 都无效），启动游戏、更新汉化等依赖游戏目录的
  功能在后端也会被拒绝执行。选到上一层目录（如 `steamapps\common`）会自动下探到唯一
  含 exe 的子目录。
- **桌面（Tk）模式**：就是系统询问窗口，没选（点取消）**直接退出启动器**。


### 🔔 贴心细节

- 🖥️ **内置迷你终端**：实时日志输出、一键复制 / 清空
- 📌 **退出后驻留系统托盘**，后台常驻
- 🔄 **自动更新**（含预发布） + 版本详情介绍窗口：启动时检查一次并留在内存，**点主页版本卡查看只读内存里的这份数据（不再联网）**；只有真去下载更新包时才访问云端
- 🎵 **自定义欢迎音效**（留空即关闭）
